Swoop trained swipe network (swipe_encoder.bin) - source, licence and notices

swipe_encoder.bin holds the weights of a small neural network (633,697 numbers, about 2.5 MB) that reads the path and timing of a glide on the keyboard and says how likely each
candidate word is. Swoop uses it as a second opinion on its own decoder (Settings > Typing > Smarter glide reading). It never leaves the device.

* The weights were trained by Parth Parekh ("compose-keyboard-swipe-encoder", https://huggingface.co/xxparthparekhxx/compose-keyboard-swipe-encoder, code
  https://github.com/xxparthparekhxx/keyboard), on the FUTO Swipe dataset (https://huggingface.co/datasets/futo-org/swipe.futo.org, MIT licence, about 900,000 real swipes).
  Both are published under the MIT licence; the model card says "license: mit" and the repository's LICENSE is reproduced below. The file is used unchanged.
* The network's design follows the FUTO Swipe paper (arXiv:2606.25247): a layout-agnostic temporal convolutional network whose output is a 2D pattern of 64 cosine coefficients read at each key.
  Swoop's own code that runs it (ShapeNet.kt, ShapeRescorer.kt) is a fresh implementation in Kotlin, checked against the original's reference numbers (ShapeNetParityTest).
* Swoop's tests use the 6 KB reference file swipe_reference.bin from the same repository (MIT).
